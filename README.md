# MART101 🛍️

**The official student marketplace for Olabisi Onabanjo University (OOU), Ogun State, Nigeria.**

MART101 is a campus-focused buy-and-sell platform built for OOU students to trade laptops, phones, textbooks, fashion items, and other student essentials safely within their own campus community.

🔗 **Live site:** [mart101.vercel.app](https://mart101.vercel.app)

---

## About

MART101 was built to solve a real problem on campus: students needed a trusted, dedicated space to buy and sell items with other verified students — instead of relying on scattered WhatsApp groups or unmoderated pages. Before launch, an early version of MART101 was used by 100+ OOU students with 300+ product listings, proving real demand for the platform.

This version of MART101 was built from the ground up — full-stack, production-grade architecture, security-hardened, and actively maintained.

## Features

- 🔐 Secure authentication (email/password + Google Sign-In)
- 🛒 Product listings with image uploads, categories, and condition tags
- 💬 In-app 1-on-1 messaging with real-time delivery, read receipts, and push notifications
- 📱 Progressive Web App — installable on any device, no app store required
- ✅ Seller verification and admin moderation tools
- 🚩 Community reporting system for listings and sellers
- 🖼️ Profile pictures via Cloudinary
- 📊 Admin dashboard with analytics, reports, and activity logs
- 🔎 Search engine optimized for discoverability

## Tech Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Supabase (PostgreSQL, Auth, Storage, Realtime, Edge Functions, Row-Level Security)
- **Media storage:** Cloudinary
- **Hosting:** Vercel
- **Push notifications:** Web Push API with VAPID

## Security

MART101 follows production-grade security practices, including:
- Row-Level Security (RLS) policies on every database table
- Strict Content Security Policy (CSP) headers
- Secure file upload validation (type & size limits)
- Admin actions logged and auditable
- Hardened authentication policies
